# System Design: AI CodeDoc Studio

## 1. Executive Summary
AI CodeDoc Studio is a full-stack web application designed to automate code documentation, visualization, and analysis. It leverages Large Language Models (LLMs) to generate documentation, flowcharts, and unit tests, significantly reducing developer overhead. The system is built on a decoupled client-server architecture using Next.js for the frontend and FastAPI for the backend.

## 2. Architecture Overview

The system follows a modern microservices-lite architecture, separating the user interface, API logic, and data persistence.

## 4. System Components

### 4.1 Frontend (Client)
-   **Dashboard**: Central hub for managing projects and viewing analysis history.
-   **Code Editor**: Integrated Monaco Editor for viewing source code and real-time documentation editing.
-   **Visualizer**: Renders Mermaid.js flowcharts generated by the backend.
-   **Authentication**: Handles user login/registration and stores JWT tokens in secure storage.

### 4.2 Backend (Server)
-   **API Layer**: Exposes RESTful endpoints for the frontend.
-   **AI Orchestrator**: Manages requests to LLM providers. Implements retry logic and fallback mechanisms (Hugging Face -> Gemini).
-   **GitHub Connector**: Fetches repository contents and file metadata using the GitHub API.
-   **Export Service**: Generates downloadable documentation formats (Markdown, PDF).

### 4.3 Data Layer
-   **User Store**: Manages user credentials and profiles.
-   **Project Store**: Stores metadata about analyzed repositories.
-   **Analysis Store**: Caches generated documentation and flowcharts to reduce API costs and latency.

## 6. API Design

### Authentication
-   `POST /auth/register`: Create a new account.
-   `POST /auth/login`: Authenticate and receive access token.

### AI Services
-   `POST /ai/documentation`: Generate docstrings and summary.
-   `POST /ai/flowchart`: Generate logic flow visualization.
-   `POST /ai/tests`: Generate unit test cases.

### GitHub Integration
-   `GET /github/repos`: List accessible repositories.
-   `GET /github/contents`: Fetch file/folder structure.

## 7. Security & Scalability
-   **Authentication**: JWT-based stateless auth with expiration.
-   **Environment Variables**: Sensitive keys (API keys, DB URL) are stored in `.env` and never exposed to the client.
-   **Rate Limiting**: (Recommended) Implement rate limiting on AI endpoints to prevent abuse.
-   **Caching**: Analysis results are cached in MongoDB to avoid redundant LLM calls for unchanged files.
